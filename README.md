# ScaleGuard releases

Публичный репозиторий только для готовых сборок ScaleGuard. Исходный код
приложения, сайта и Telegram-бота хранится в приватных репозиториях.

## Скачать

* [Последний релиз](https://github.com/INZEWORLD/ScaleGuard/releases/latest)
* Windows: `ScaleGuard-Setup-<version>.exe`
* Android: `ScaleGuard-android-<version>.apk`
* Android TV: `ScaleGuard-TV-<version>.apk`

Сайт: https://scaleguard.inzeworld.com

Приложение само проверяет новые версии через GitHub Releases API и
предлагает установить обновление, если файл для его платформы новее.
